## GTA VI at 4K Overview

A 4K HDR setup has three links: the game, the Windows output, and the display. Any one of them can silently disable HDR, and the result still looks plausible, which is why verification matters more than the toggles themselves.

The order is fixed by how the signal travels. The display must be in its HDR mode for the input in use, Windows must report the output as HDR capable, and the game must then be told to use it. Changing them out of order produces a picture that looks almost right.

Comparisons usually set native 4K against an upscaled target, and HDR against a tone-mapped SDR image. Both pairs change how much work the GPU does, so a 4K HDR configuration is also a performance decision, not only a picture one.
